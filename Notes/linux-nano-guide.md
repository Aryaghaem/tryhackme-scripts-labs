Topic: How to edit files in Linux using Nano
To open/create a file: nano filename.txt
To save: Press Ctrl + O, then Enter.
To exit: Press Ctrl + X.
Why this matters: In Cyber, we often have to edit configuration files or write scripts quickly in the terminal.
